\title{VANISH: Design and Implementation of a Cross-Platform, Cryptographically Verifiable Self-Expiring Digital File Protocol}

\author{
\IEEEauthorblockN{Anonymous Author(s)}
\IEEEauthorblockA{\textit{Research Laboratory for Systems Security and Privacy}}
}

\maketitle

\begin{abstract}
Traditional operating systems treat stored digital files as permanent artifacts. While secure messaging apps provide disappearing messages, their protection is limited to app sandboxes; once an attachment is downloaded to storage, it remains indefinitely. Previous academic proposals for self-destructing data relied on peer-to-peer distributed hash tables, which were later shown to be vulnerable to Sybil crawling attacks.

In this paper, we propose \textbf{VANISH}, an open, cross-platform protocol for self-expiring digital files with native operating system enforcement. VANISH encapsulates arbitrary files into a self-describing container (\texttt{.vfile}) with Canonical CBOR metadata, Ed25519 digital signatures, and optional AES-256-GCM encryption. Receiving operating systems natively verify the container, track its lifetime, and automatically delete or cryptographically shred the file upon expiration. Our evaluation shows that VANISH adds only $429$\,bytes of framing overhead, completes verification in $1.45$\,ms per megabyte, and achieves exact expiration on Android with zero idle battery drain.
\end{abstract}
